# ติดตั้งระบบจองคิว naaiprem.foto

ระบบจองคิวในเว็บจะส่งข้อมูลไปเก็บใน **Google Sheets** ของคุณเอง
ใช้เวลาตั้งค่าครั้งแรกประมาณ 10 นาที ทำครั้งเดียวจบ

สิ่งที่ได้หลังติดตั้ง:
- ทุกคำขอจองจะเข้าเป็นแถวใหม่ในชีต "การจอง" และส่งอีเมลแจ้งเข้า Gmail ของคุณ
- สลิปมัดจำที่ลูกค้าแนบ จะเก็บไว้ใน Google Drive โฟลเดอร์ "naaiprem.foto — สลิปมัดจำ"
- พอเปลี่ยนสถานะเป็น **มัดจำแล้ว** วันนั้นจะลง Google Calendar ให้เอง และบนเว็บจะขึ้นว่าไม่ว่าง

---

## ขั้นที่ 1: สร้าง Google Sheet

1. เปิด https://sheets.new (ล็อกอินบัญชี Google ที่จะใช้ดูการจอง)
2. ตั้งชื่อไฟล์ เช่น `naaiprem.foto — การจอง`

## ขั้นที่ 2: ใส่สคริปต์

1. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกให้หมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs` ในโปรเจกต์นี้ไปวาง
4. กดไอคอน 💾 บันทึก

## ขั้นที่ 3: กดติดตั้ง

1. ที่แถบด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด **▶ Run (เรียกใช้)**
2. Google จะขอสิทธิ์ ให้กด **Review permissions** แล้วเลือกบัญชีของคุณ
3. จะเจอหน้า **"Google hasn't verified this app"** ซึ่งเป็นเรื่องปกติ เพราะเป็นสคริปต์ที่คุณสร้างเองในบัญชีตัวเอง
   ให้กด **Advanced** แล้วกด **Go to … (unsafe)** แล้วกด **Allow**
4. กลับไปดูที่ชีต จะมีแท็บ **การจอง** กับ **ปิดรับ** ขึ้นมา

## ขั้นที่ 4: เปิดเป็น Web app

1. ในหน้า Apps Script กด **Deploy (การทำให้ใช้งานได้) → New deployment**
2. กดรูปเฟือง ⚙ แล้วเลือก **Web app**
3. ตั้งค่าตามนี้
   - **Execute as:** `Me` (ตัวคุณเอง)
   - **Who has access:** `Anyone` (ทุกคน)
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 5: เชื่อมกับเว็บ

ส่ง URL จากขั้นที่ 4 มาให้ หรือวางเองที่ `js/data.js` ในส่วน `BOOKING.endpoint`
แล้วกรอกบัญชีรับมัดจำในส่วน `BOOKING.deposit` (พร้อมเพย์ / ธนาคาร / เลขบัญชี / ชื่อบัญชี)

ถ้ายังไม่ใส่ `endpoint` ส่วนจองคิวจะถูกซ่อนไว้ และปุ่ม "จองคิว" ยังพาไปทักแชทเหมือนเดิม

---

## ใช้งานประจำวัน

**ชีต "การจอง"**: คอลัมน์ **สถานะ** เลือกได้จากรายการ

| สถานะ | ความหมาย | บนเว็บ |
|---|---|---|
| รอคุย | ลูกค้าเพิ่งส่งคำขอ ยังไม่โอน | ยังว่าง |
| รอตรวจสลิป | ลูกค้าแนบสลิปแล้ว รอคุณเช็กยอด | **ไม่ว่าง** |
| มัดจำแล้ว | ตรวจยอดแล้ว ยืนยันคิว | **ไม่ว่าง** และลง Google Calendar |
| ถ่ายแล้ว / ส่งงานแล้ว | ติดตามงาน | (วันที่ผ่านไปแล้ว) |
| ยกเลิก | ยกเลิกการจอง | ว่างอีกครั้ง และลบออกจาก Calendar |

- ช่อง **หมายเหตุ (ของเรา)** ใช้จดอะไรก็ได้ เช่น ยอดมัดจำ หรือนัดเจอจุดไหน
- กดลิงก์ในช่อง **สลิป** เพื่อเปิดดูรูปสลิป

**ชีต "ปิดรับ"**: ใช้ปิดวันที่ไม่รับงาน
- พิมพ์วันที่แบบ `2026-12-31` (ปี ค.ศ.) หรือ `31/12/2569` ก็ได้
- ถ้าไม่ว่างทั้งวัน ให้เว้นช่อง "เริ่ม" กับ "ถึง" ไว้ ถ้าไม่ว่างแค่บางช่วง ให้ใส่เวลา เช่น `09:00` ถึง `12:00`

**เมนู naaiprem.foto** (อยู่บนแถบเมนูของชีต)
- **ซิงก์ Google Calendar ทั้งหมด**: ใช้ถ้าปฏิทินไม่ตรงกับชีต
- ถ้าแก้วันหรือเวลาของงานที่ "มัดจำแล้ว" ให้เปลี่ยนสถานะเป็น "รอคุย" ก่อน แล้วค่อยเปลี่ยนกลับเป็น "มัดจำแล้ว" นัดในปฏิทินจะอัปเดตตาม

## ปรับตั้งค่า (ในไฟล์ Code.gs ส่วน `CONFIG` ด้านบน)

- `BUFFER_MINUTES`: เวลาเผื่อเดินทางก่อนและหลังแต่ละงาน (ตั้งไว้ 60 นาที)
- `MIN_DAYS_AHEAD`: ต้องจองล่วงหน้ากี่วัน (ตั้งไว้ 1 = จองได้ตั้งแต่พรุ่งนี้)
- `NOTIFY_EMAIL`: อีเมลที่รับแจ้งเตือน (ว่างไว้ = ส่งเข้าบัญชีที่ติดตั้ง)

ส่วนแพ็กเกจและเวลาของแต่ละงานแก้ที่ `js/data.js` (ส่วน `BOOKING.types`)

> ⚠️ **แก้ Code.gs แล้วต้อง Deploy เวอร์ชันใหม่** ไม่งั้นเว็บยังใช้โค้ดเดิมอยู่
> ไปที่ **Deploy → Manage deployments** กดรูปดินสอ ✏️ ตรง Version เลือก **New version** แล้วกด **Deploy**
> (ทำแบบนี้ URL จะเหมือนเดิม ไม่ต้องแก้เว็บ)
